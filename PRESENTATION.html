How it works

  • ✅ Grayscale → single channel for edge detection
  • ✅ Gaussian blur → removes noise from camera artifacts
  • ✅ Canny edges → finds building boundaries at 50/150 thresholds
  • ✅ Morph close → bridges small gaps in edges
  • ✅ Contour filter → keeps only large rectangular shapes
  • ✅ Height est. → 8m base + area_ratio × 180m
  • ✅ Type classify → area ratio buckets (low/mid/high/mixed/commercial)

Feature #5 — Dynamic 3D City

Procedural 3D city twin with drill-down

🏗️

Dynamic Building Generation

  • • Height → extrusion height from DB
  • • Floors → floor-slab edge lines
  • • Footprint polygon → ExtrudeGeometry from real points
  • • Type color → cyan/green/pink/violet per building class
  • • Hover/select → emissive glow + label tooltip
  • • Rooftop beacon → pulsing octahedron marker
📐

Interactive Controls

  • • Orbit → drag to rotate around the city
  • • Zoom → scroll to fly in/out
  • • Explode slider → separate floor slabs to see interiors
  • • Underground toggle → show/hide pipes
  • • Text filter → search buildings by code or type
  • • Building list → sidebar with all towers
🔍

Drill-Down Panel

  • • Click any building → Parcel info
  • • See building code, height, type, AI confidence
  • • Expand each Floor → see units
  • • Each unit shows: number, area, type, owner status
  • • Full Parcel → Building → Floor → Unit tree
  • • Same hierarchy available via REST API
